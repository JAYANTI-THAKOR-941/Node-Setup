# Node.js API Setup

Node backend with product and user controllers, models, routes, authentication middleware and token generation.

## Project structure

- `index.js`
- `config/db.js`
- `controllers/`
- `models/`
- `routes/`
- `middlewares/isAuth.js`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Node-Setup.git
cd Node-Setup
```

Run `npm install`, configure local database and token settings, then start using the package scripts or `node index.js`.

## Security

A credential-related file is tracked in this repository. Review it privately, rotate any real credentials it contains, and use ignored local configuration files. Never publish secret values.
